# 8. 编辑器：从截图到词条

## 这一章能做什么

- 上传一张截图，成为项目里的一个 Page
- 在截图上画框、移动、缩放、锁定、删除
- 用 **OCR** 把框里的字读成原文
- 给框绑一条词条：让 AI 起名、手填 key，或者从已有词条里挑一条
- 填各语言的译文
- 切页面、改页面设置

## 编辑器长什么样

左边是 **Pages** 列表，右边是画布，画布上方一条工具栏。当前页在列表里高亮，画布上是它的截图。

[image 编辑器整屏标注图：左侧 Pages 列表（含 Add new page 和页面行）、顶部工具栏（缩放、三个模式、线宽、颜色、Help）、画布上的截图、一个被选中的框和框上方那一条图标按钮]

## 页面列表

### 上传一张截图

两种入口，打开的是同一个 **New Page** 弹窗：

- 列表顶部的 **Add new page**（列表还是空的时候，那一块是个虚线框，写着 `Drop Image here to create new page`）
- 直接把图片文件拖到左边列表这片区域上：拖完自动打开弹窗，图也带进去了

弹窗里 **Name** 至少要 3 个字符，**Image** 选一张图，两样缺一个都建不出来。标签页是 **Basic** / **Prompt** / **Settings**，后两个见第 6 章的「页面级设置」。

新页面出现在**列表最上面**。项目里本来一张页面都没有时，它直接成为当前页；已经有别的页面时，你还留在原来那一页，点一下新的才切过去。

### 页面行上有什么

鼠标停在页面行上会弹出这张截图的预览。行尾的 ⋮ 有两个菜单项：

- **Page Settings**：改名、换图、改这一页的 OCR、Prompt、key 命名规范、发行标签。
- **Delete Page**：确认框 `Are you sure you want to delete this page?`。**删页面会连同这一页上所有框一起删掉，截图文件也一并删除。** 词条本身还在，只是少了这些引用（到词条表里看）。

点另一行就切过去。切换前如果框有没保存的改动，会先问一句（见下面「自动保存」）。

## 工具栏

从左到右：

| 控件 | 做什么 |
|---|---|
| **−** / 百分比 / **+** | 缩小、放大。百分比下拉里是 **100%** / **50%** / **125%**，加减按钮每次 10% |
| 手形 | **Drag** 模式：只平移画布，点不到框 |
| 铅笔尺 | **Add Tag** 模式，默认 |
| 鼠标指针 | **Edit Tags** 模式 |
| 线宽 | **1px** / **2px** / **4px** |
| 颜色 | 取色器，任意颜色。线宽和颜色**只作用于之后画的框**，已有的框去 Info 里改 |
| **?** | **Editor help** 抽屉，就是这一章画布部分的同一套说明 |

## 三种模式

一次只能选中**一个**框，也没有框选。

| 模式 | 单击一个框 | 在空白处拖拽 | 拖拽画布 |
|---|---|---|---|
| **Add Tag**（默认） | 选中它 | 画出一个新框 | 不能 |
| **Edit Tags** | 选中它 | 什么也不发生 | 不能 |
| **Drag** | 不选中，框在这一模式下点不到 | 平移画布 | 能 |

**Add Tag 是唯一能画出新框的模式**，也是唯一能在**锁定的框上面**画新框的模式——锁住的框不会拦住拖拽。这是它的主要用途：先把一整块大区域框起来锁住，再在上面逐条画小的。

## 画一个框

在 **Add Tag** 模式下，在截图上按住拖出一个矩形，松手就画好了。

- 拖得太小（宽或高不到 10 像素）算一次点击，不会画出框来。
- 框会被限制在截图范围内，拖出边界也不会跑到图外面去。
- 刚画好的框**还没有绑词条**，画布上也不显示标签——去 Info 里给它 OCR 或者挑一条词条。

## 选中一个框

点一下框，框的**上方**出现一条小图标工具栏，五个按钮：

| 图标 | 做什么 |
|---|---|
| 锁 | **Lock**：锁住或解锁 |
| i | **Info**：打开 Tag Info 弹窗 |
| 链条 | **Link**：绑一条已有词条 |
| OCR | 读框里的文字 |
| × | 删除这个框 |

**双击框**也直接打开 Info，和点那个 i 一样。

**锁定**只禁止移动和缩放：框在 **Edit Tags** 模式下拖不动，但照样能选中、能打开 Info、能在它上面画新框。锁定状态会跟着框存下来，下次打开还是锁着的。

## OCR：把框里的字读成原文

选中框 → OCR 按钮。读的是**这一页的 OCR 语言**（页面设置里的那个，默认继承项目）。读出来的文字会变成这条框对应词条的原文。

- 失败会弹 **Failed to OCR image**。
- 成功弹 **Translation created**，框上随即出现一个 `__draft_` 开头的标签。

`__draft_…` 是系统给还没起名的词条自动建的占位 key，界面上只显示 `__draft_` 加 5 位短哈希。同一个项目里，**原文一模一样**（忽略空白）的框会算出同一个占位 key，所以重复贴同一句文案不会建出一堆词条。

## Info：给框绑一条词条

四个标签页：**Basic** / **Styles** / **Prompt** / **Translations**。

- **Basic**：裁出来的小图、只读的 ID / TagID / Size / Position，以及 Position 那一行的锁定按钮。
- **Styles**：这条框的外观——描边颜色与粗细、圆角、标签文字的颜色、粗细、字号、对齐。
- **Prompt**：只给这条框的 AI 命名用的提示词。
- **Translations**：词条本身。下面细讲。

### Translations 标签页

**还没有词条时**，中间写着 `No translation yet`，下面给三个选择：

- **Link an existing translation**：打开 **Select Translation** 弹窗，表里一列一个语言，**第一列语言就是原文**（本项目的源语言），勾一条再点 **Link** 挂上。搜索框搜 key，也搜任意语言的文案。
- **Create New**：弹一个小窗（标题 **Input Dialog**，提示 `Enter the original text to create`），填一句原文后按它建一条词条。
- **Create with OCR**：同上面的 OCR。

**已经有词条时**，从上到下是：

- **I18n Key**：这条词条的 key（`__draft_…` 时显示短哈希），右边一个 **AI** 按钮。
- **Releases**：发行标签。说明写着 `Labels on the translation entry, not on this box.`——标签挂在词条上，不挂在这个框上（第 7 章）。
- **国旗图标 + 语言名那一块**（例如 **English**，就是本项目的源语言，第 6 章）：原文填在这里。标签旁边三个小按钮：**Link**（换绑另一条词条）、**New**（只在原文被你改过时才出现）、**History**（这条词条的改动记录），右边还写着它的 Finger。
- **Translations**：选一个语言，填这个语言的译文；右上角 **Vue** / **React** 两组分开存。源语言**不在这个下拉里**——它就在上面那一块，一个语言只有一个输入框。

底部是 **Cancel** / **Save**。**Info 里改的东西要点 Save 才落库。**

### 让 AI 起名

先在源语言那一块填上原文，再点 **I18n Key** 旁边的 **AI**。出现的那块面板写着 **AI suggestion**，带一个匹配度百分比（越高越绿），下面是它挑的 key，还有：

- **Candidates**：模型给的其它候选，换一个看。
- 一行 reason：它为什么这么起名。
- 右上角的 ✕ 关掉这块面板；✓（有候选时才出现）把选中的候选**填进输入框**。

**选中候选不等于保存**——它只是填进输入框，你还要点 **Save** 才算数。

面板下面可能出现这几种提醒卡：

| 卡片 | 意思 |
|---|---|
| **Does not match the key convention** | 生成的 key 不符合项目的命名规范，下面逐条写哪里不合规 |
| **The model changed the source text** | 模型把你给的原文改写了，卡片里显示它改成了什么——**以这个为准去核对**，原文本身没被动过 |
| **Already in this project** | 这个 key 已经被占了，但**原文一模一样**——多半是重复的词条，可以直接复用 |
| **This key is taken** | 这个 key 属于**另一条文案**，卡片里写着那条文案是什么 |

最后两张是同一个冲突的两种情形，不会同时出现。

项目、页面、标签**三层 Prompt 都会参与**这次生成。

### 保存时会怎样

| 你改了什么 | 结果 |
|---|---|
| 只改译文 / 样式 | 存进当前这条词条 |
| 改了 **I18n Key** | 给当前这条词条**改名**。多个框共用它的话，一起改 |
| 改成一个**已被别的文案占用**的 key | 保存后这条框会挂到**那条已有词条**上，你在这个框里填的原文不生效 |
| 改了源语言那一块的原文 | **原地改这条词条的原文**，和词条表里改源语言那一格是一回事。多个框共用这条词条的话，它们一起变 |
| 点 **New**（原文那一行右侧的按钮） | 按当前原文**另建一条**词条，这个框改挂到新的那条上；原来那条留在项目里，别的框可能还指着它。项目里已有相同原文时，会先问你复用还是新建 |

**New** 碰到「已有相同原文」时，弹的那个窗长这样：标题 **Warning**，正文 `This translation already exists. Do you want to recover it?`，另有提示 `Create new translation may generate a repeating translation. Make sure to create it carefully.`，按钮是 **Create New** 和 **Recover**。**Recover** 把这条框挂到已有的那条词条上，**Create New** 另起一条。这个弹窗点不掉，必须二选一。

## 删掉一个框

选中框 → × 按钮，或者按 `Delete` 键。

- 框里**有原文或译文**时，先弹确认框：**Delete Tag** / `This tag has content text or translations. Are you sure you want to delete it?`。
- 空框直接删掉，不啰嗦。

**删框只去掉这个标注。** 词条不跟着走——那条词条还在词条表里，别的框也可能还指着它。

## 自动保存

框的移动和缩放不会立刻写回服务端，而是攒着：

- 第一次改动之后 **2 分钟**统一保存一次。
- `Ctrl+S` 立刻保存，弹 **Tags saved successfully**。
- 切页面、切项目之前如果还攒着改动，弹 **Warning** / `You have unsaved changes. Do you want to save them now?`，选 **Save Now** 或 **Cancel**。
- 直接关浏览器标签页也会被拦一下。

Info 弹窗里的改动不属于这一类，它们点 **Save** 就走了。

## 做错了会怎样

| 你看到 | 原因 |
|---|---|
| 画布中央写着 `Oops, No Page or Image Found` | 这个项目还没有页面，或者这一页没有截图。先去左边传一张 |
| 在 **Edit Tags** 模式下拖空白处，画不出框 | 画框只在 **Add Tag** 模式里 |
| 在 **Drag** 模式下点框没反应 | 这个模式框是点不到的，切回 **Add Tag** |
| 拖了一小段，没画出框 | 宽或高不到 10 像素，被当成一次点击了 |
| 框拖不动 | 它被锁了。用框上方那把锁解开 |
| 想改线宽和颜色，已有的框没变 | 这两个只作用于**之后画的**框；改已有的去 **Styles** 标签页 |
| 想选好几个框一起动 | 一次只能选一个，也没有框选 |
| 点了 **AI**，面板上说 `Nothing in this text can be named.` | 框里那句原文起不出名字（比如纯符号），先确认源语言那一块里有内容 |
| AI 给的 key 提示 `This key is taken` | 这个 key 已经是别人的。换一个，或者确认要复用那条词条 |
| 改了原文那一块保存后，词条表里多出一条 | 你点的是 **New** 不是 **Save**。**New** 是故意另建一条（上表）；只想改原文就按 **Save** |
| **Translations** 的语言下拉里找不到源语言 | 它不在下拉里。源语言的原文就在上面那一块，一个语言只给一个输入框 |
| 改了 key 保存后，别的框上的标签也变了 | 这些框共用同一条词条，改名是一起改的 |
| 关标签页时浏览器弹了「离开网站？」 | 还有没保存的框改动，先回编辑器按一下 `Ctrl+S` |
| 从词条表点 Edit 跳过来，选中的不是我点的那条框 | 点的那条 key 在这一页有多个框时，跳的是第一个；用框上方的 Info 确认 |
