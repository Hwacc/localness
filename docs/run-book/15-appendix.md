# 15. 附录

## 名词表

| 名词 | 意思 | 详见 |
|---|---|---|
| **Page** | 一张截图，就是一个页面 | 第 8 章 |
| **Tag** | 截图上的一个框。框本身只是个标注，内容全在它指向的词条上 | 第 8 章 |
| **词条**（i18n key） | 一条待翻译的文案。按项目唯一，一个语言一份草稿 + 一份已发布。同一 key 可以被多个框共用 | 第 9 章 |
| **Draft** | 从未发布过，或者任一语言的草稿和已发布不一致 | 第 2 章 |
| **Published** | 每个语言的草稿和已发布都一致。已发布的词条只读 | 第 2、9 章 |
| `__draft_…` | 系统给「还没起名」的词条自动建的占位 key，界面上显示成 `__draft_` 加 5 位短哈希。正文一模一样（忽略空白）的框会共用同一个 | 第 2、8 章 |
| **Release** | 挂在页面和词条上的发行标签，用来缩小范围和按发行导出 | 第 7 章 |
| **Unassigned** | 还没挂任何发行标签的那些内容 | 第 7 章 |
| **Team** | 管一组项目和一批成员 | 第 5 章 |
| **Project** | 管一批页面、词条和配置。一个 Team 下可以有多个 | 第 6 章 |
| **Team Member** / **Project Owner** / **Team Owner** / **Admin** | 四种身份。前三个是队伍/项目角色，Admin 是账号级身份 | 第 14 章 |
| **调用方** | 不进界面，拿一枚只读 token 取已发布文案 | 第 12 章 |
| **Source language** | 原文存在哪个语言下。**原文就是它在那一格的文本**，界面上没有单独的字段；它的那一列也是导出表里的原文列 | 第 6 章 |
| **product** | Git 仓里这个项目对应的那个目录，`source/` 和 `translated/` 就在它下面 | 第 11 章 |
| **批次文件** | 远端 `source/` 里一次 Push 产生的一个新 JSON 文件，只增不改 | 第 11 章 |
| **Pull** / **Push** | 把 Git 上领先的文案落到平台 / 把平台的已发布源语言推成一个新批次 | 第 11 章 |
| **冲突卡片** | Git 和平台两边都改了同一条 key 的同一种语言时，用来裁决的那张卡 | 第 11 章 |
| **API token** | 只读凭证，绑一个项目，明文只在创建时出现一次 | 第 12 章 |
| **MCP** | 同一枚 token 的另一副面孔，给 agent 直接查 | 第 12 章 |
| **skill** | 按项目存放的、给 agent 用的说明包 | 第 13 章 |

## 常见问题

**发布了，但导出的文件里没有这条词条。**

先确认它真的发布了——词条表的 **Status** 列还是 **Draft** 的话，说明还有语言的草稿和已发布不一致（发布时提示 `Nothing to publish` 也是这个意思）。其次看导出时 Workspace Bar 上的发行筛选是不是把它挡在外面了，以及第 2 步的词条选择表里有没有勾上它。第 9、10 章。

**AI 给的 key 提示 `This key is taken`。**

这个名字已经属于**另一条文案**了。换个名字，或者确认你就是要复用那一条——在编辑器里把框挂过去，或者到那边改掉它的名字。第 8、9 章。

**Git 页上的 Push 按钮是灰的。**

还有没解决的冲突卡片，卡片上方会写着 `N open conflict(s)`。裁决完记得回词条表**发布**一次：冲突裁决写的是草稿，不发布就不会进下一次 Push。第 11 章。

**某条词条的格子是灰的，改不动。**

它已经发布了。已发布只读，先 **Revert to draft** 撤回成草稿再改。第 9 章。

**编辑器左边的页面列表空了，画布上写着 `Oops, No Page or Image Found`。**

多半是当前发行筛选把它收窄没了——点 **Show all pages**，或者把 Workspace Bar 的发行切回 **All releases**。项目里真的一张页面都没有时也是这个提示。第 7、8 章。

**撤回一条词条之后，导出和 API 里都找不到它了。**

正常。撤回会把**已发布文字清空**，草稿还在，改完再发布一次就回来了。第 9 章。

**把词条移动（Move）到别的项目之后，截图上的框空了。**

移动只带走各语言的文案，不带截图上的框。框还在原地但失去了绑定，回编辑器重新挂一条词条就行。第 9 章。

**token 的明文找不回来了。**

明文只在创建的那一次显示，服务端只存哈希。吊销这一枚，重新建一枚。第 12 章。

**agent 说没有这个 release，或者查不到某条 key。**

release 名让它先调 `get_project_info`（合法值写在那里）。key 查不到最常见的原因是它还没**发布**——草稿不进对外 API，也不会拿别的语言补上。第 12 章。

**我只改了一个框的标签，编辑器里另外几个框跟着变了。**

标签挂在**词条**上，不在框上。这几个框共用同一条词条，改的是一份。第 7、8 章。

**有些入口我根本找不到。**

**Project settings**、Project Settings 里的 **Releases** 标签页、发行下拉里的 **Manage releases…**、Teams 页的 **Invite codes** 和 **Invite**——这些不是藏起来了，是你的角色没有权限。第 14 章那张表对一下。

**删一条词条时，确认框说会连删几个框。**

删 key 会连截图上的框一起删掉，这一条和编辑器里删框（只去标注、词条还在）刚好相反。第 9 章。

**在编辑器里点了 New，词条表里多出一条。**

**New** 是故意另起一条：按当前原文新建一条词条，这个框改挂到新的那条上，原来那条留在项目里（别的框可能还指着它）。只想改原文，按 **Save** —— 那是原地改，和词条表里改源语言那一格是一回事。第 8 章。

**同事看到的页面数或词条数和我不同。**

发行筛选和词条表的筛选都记在**你自己的浏览器上**，一个项目一份，不是团队设置。第 7、9 章。

## 不在本手册范围

| 事项 | 说明 |
|---|---|
| 公开注册 | 没有注册入口。账号只有两个来源：Atlassian 首次登录自动开户，或者管理员离线开好（第 3 章） |
| **Agent** 页 | 未开放。点进去只有一个动画和一句 `Building...`，没有任何功能（第 4 章） |
| 审批 / 审核步骤 | 没有。平台只有 Draft → Published 这一个状态流转，发布不需要别人点头（第 9 章） |
| 复数 / 数组类词条 | 没有。一条词条就是一个字符串，没有复数形式，也没有多值 |
| 从别处导入 JSON | 没有导入入口。词条只能建在平台里，或者由 Git 同步带进来（第 11 章） |
